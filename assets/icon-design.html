Shuffle 管家 · 图标设计稿

为 iPod Shuffle 管理工具设计专属图标，替换 Electron 默认图标。
三套矢量方案，均为 512×512 圆角 App 图标，可直接导出 PNG / ICO 接入 Electron。

推荐
方案 A · 设备本体

最直白的方案：白色 iPod Shuffle 机身 + 顶部背夹 + 圆形控制盘 + 播放键，右下角点缀音符。一眼认出「这是 iPod 工具」。

方案 B · Shuffle 符号

用 Apple Shuffle 经典的交叉箭头作为主图形，呼应产品名「Shuffle」，抽象、现代、极简。辨识度高且不依赖设备外观。

方案 C · 极简音符

单个八分音符置于紫→青科技渐变底板上，最简洁、最「未来科技感」。弱化了设备特征，强调整体工具的现代气质。

选定方案后，我会：① 导出多尺寸 PNG 与 Windows ICO（16/32/48/256）；
② 在 package.json 的 build.icon 与主进程 BrowserWindow 中接入，彻底替换 Electron 默认图标。
